# Minimal inference gui for WFL ASR

A minimal inference gui made by yours truly because i wanted to keep wfl as stripped down as possible (due to low storage on my pc and also because i prefer more straightforward and efficient usage).

@ Setup
Download WFL-ASR repo from [here](https://github.com/MLo7Ghinsan/WFL-ASR) (Code -> Download ZIP)
Download infer_gui.py, setup.bat and run_gui.bat from this repo
Extract the WFL-ASR zip into a folder and then place the files you just downloaded into the folder
Run setup.bat and wait until it finishes
Run local_gui.bat once setup has finished
